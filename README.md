# Banner element for Silverstripe

Simple banner image element with content, image and link.

## Link migration

If you are migrating from 2.0, go through 2.1 first to get a staged migration of links (2.0 -> 2.1 -> 3.0)

## Requirements

See composer.json

## Installation

```sh
composer require nswdpc/silverstripe-elemental-banner
```
